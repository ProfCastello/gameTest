# Palavras Cruzadas - Jogo em Português 🧩

Um jogo de palavras cruzadas completo desenvolvido em HTML, CSS e JavaScript puro, otimizado para tablets e dispositivos móveis, com palavras em português brasileiro.

![Menu Principal](https://github.com/user-attachments/assets/4a17ac22-7307-4610-9c42-1c52407d68e4)

## 🎯 Características

### 🎮 Funcionalidades do Jogo
- **6 Níveis de Dificuldade**: Escolha entre 5, 10, 15, 20, 30 ou 50 palavras
- **Geração Automática**: Algoritmo inteligente que cria palavras cruzadas com intersecções
- **Base de Dados**: Mais de 120 palavras em português brasileiro com dicas
- **Teclado Virtual**: Teclado completo na tela incluindo caracteres especiais (Ç)
- **Sistema de Dicas**: Obtenha ajuda revelando uma letra por vez
- **Verificação de Respostas**: Valide seu progresso e veja palavras completadas
- **Navegação Intuitiva**: Clique nas células ou dicas para navegar

### 🎨 Interface Moderna
- **Design Gaming**: Cores modernas usadas em jogos de puzzle atuais
- **Fundo Animado**: Gradientes dinâmicos com efeitos de movimento
- **Responsivo**: Funciona perfeitamente em tablets, celulares e desktops
- **Efeitos Visuais**: Animações, efeitos de brilho, transições suaves
- **Touch Friendly**: Botões grandes otimizados para uso touch

![Jogo em Ação](https://github.com/user-attachments/assets/43ddd2a6-20af-488f-9897-4936ee7514f6)

## 🚀 Como Jogar

1. **Escolha a Dificuldade**: Selecione quantas palavras deseja no puzzle
2. **Navegue no Grid**: Clique em uma célula ou dica para selecionar uma palavra
3. **Digite as Respostas**: Use o teclado virtual ou físico
4. **Use Dicas**: Clique no botão "Dica" para revelar uma letra
5. **Verifique Respostas**: Use "Verificar" para ver seu progresso
6. **Complete o Puzzle**: Preencha todas as palavras para vencer!

## 🎓 Como Usar

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/ProfCastello/gameTest.git
   ```

2. **Abra o arquivo**:
   ```bash
   cd gameTest
   # Abra index.html em qualquer navegador moderno
   ```

3. **Ou sirva localmente**:
   ```bash
   # Usando Python
   python -m http.server 8000
   # Ou usando Node.js
   npx serve .
   ```
